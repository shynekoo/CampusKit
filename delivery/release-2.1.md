## 删课表不再删背景

背景图原来存在**每张课表自己的**存储里，删课表时整份清空，图就跟着没了。现在背景是**全应用一张图**，放在独立的 `timetable-art-v1` 里：

- 删课表只删课程、开学日期、导入记录；背景保留，剩下的课表继续用同一张图；
- 换课表也不换背景——它是「外观」，不是课程数据；
- 老版本把图存在课表里的情况，在第一次读取时、以及**删那张课表之前**自动搬到共用位置，不会因为升级顺序不同丢图；
- 删除确认框改成「这个课表的课程和导入记录会一起删除，无法恢复。背景图片是全局的，会保留。」
- 备份导出带的是共用背景；恢复备份只替换当前课表的课程，同时把备份里的图设成全局背景；
- 「数据与隐私 → 清除全部本机数据」仍然连背景一起清掉。

## 公告那句话说错了

原文写「本应用对设备和订单只做查询，不代下单、不代扣费」——不对。扫浴室、饮水机的码，设备是真的会启动、真的会出水、真的按用量扣钱（启动那一步通常交给支付宝或慧生活原版完成）。现在改成：

> **扫码会真的开始用水**
> 扫浴室、饮水机的设备码不是预览：设备会被启动，当场出水或运行，费用由趣智校园、慧生活按实际用量结算，可能直接从余额或绑定的支付方式里扣。启动这一步通常由支付宝或慧生活原版完成，本应用只负责把设备交给它们；本应用不充值、不代下单，但水是你在用。设备不在眼前时不要扫，要停下请立即结束用水，或改在原版操作。

公告文案版本号 1 → 2，所以之前勾过「以后不再提醒」的人也会重新看到一次——改了内容却没人看见，等于没改。隐私页的网络去向也同步改了措辞：「设备与订单查询」→「设备状态与用水启停」。

## 课表管理去掉两项

「管理」菜单末尾的**查成绩**、**查空教室**删了。这两项在首页「教务」卡里各有一个磁贴，从那里进更直接；菜单里再放一份只是把列表拉长。

## 空教室：三个关键选项突出

周次、星期、节次决定查询结果，教学楼、场地类型、校区绝大多数时候用默认值。原来六个长得一模一样，看不出该动哪个。现在：

```
┌──────────┬──────────┬──────────┐
│ 周次      │ 星期      │ 节次      │
│ 第 12 周▾ │ 周三▾     │ 1-2 节▾   │
│ 本周      │          │ 08:00-09:35│
└──────────┴──────────┴──────────┘
  教学楼 不限    场地类型 普通教室    校区 主校区
```

- 前三个：浅蓝底 + 描边 + 蓝色加粗值 + 下拉三角，70dp 高，点按有水波；
- 后三个：一行淡灰色小字，44dp 高，不再抢视线；
- 「本周」从值里挪到下方小字，值只留「第 12 周」，长名字不会在小格子里被截断。
