## 删除课表改成按钮

原来删课表要长按那一行，弹一个「重命名 / 删除」的小菜单——长按本来就难发现，按下去还会跟「点一下切换」抢手势。现在长按彻底去掉了，每一行右侧并排两个按钮：

```
我的课表          当前
辅助课表    删除   切换
```

- **删除**：红色文字，点一下弹确认框；
- **当前 / 切换**：蓝色，当前那张显示「当前」，点不动。

删的是正在看的那张时，确认框会先告诉你删完会落到哪张——「删除后会切到「辅助课表」。这个课表的课程、背景和导入记录会一起删除，无法恢复。」不是删完才发现自己被扔到别的课表里。只剩一张时点删除，直接提示「至少要保留一个课表」，不会弹确认框。

## 三角放大一点

标题那个实心三角形从 11dp 调到 13dp，与 20sp 的课表名的比例更协调，点击区域也跟着变大了一点点。名字和三角仍是唯一可点的部分，右边空白照旧不响应。
