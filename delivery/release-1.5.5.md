# 科信小助手 1.5.5（原名 CampusKit）

2026-11-16。版本代码 150，`delivery/科信小助手-1.5.5.apk`，
sha256 `91b79bf23dfe7fbfc84577531ab1ee3e785c4d0ae230489cc31a0925a0198c37`。
签名密钥与 1.5.4 相同，包名仍是 `io.qzxy.lite.preview`，可直接覆盖安装，数据全部保留。

这一版两件事：**改名叫「科信小助手」**，**课表可以有多张**。

## 改名

应用显示名、桌面图标下的名字、三个课表组件的标签、页脚、公告、各处提示里的 CampusKit 全部换成「科信小助手」。

三处**故意没改**，改了会出事：

| 保留 | 为什么 |
|---|---|
| 包名 `io.qzxy.lite.preview` | 改包名等于换一个 App，覆盖安装会变成两个图标、数据带不过去 |
| 备份格式 `"format":"CampusKit.timetable"` | 改了就认不出之前的导出文件 |
| HTTP User-Agent 里的 `CampusKit/…` | 只是给服务器看的 ASCII 标识，中文写进请求头要额外编码，没必要动 |

构建脚本里 `FIELD_LABEL` 也一起改了——之前它会在打包时把 label 覆盖回 `CampusKit`，只改清单是没用的。

## 多课表

课表页左上角原来的「课表」两个字，现在**就是当前课表的名字**（默认「我的课表」），右边带一个小三角。点它弹出课表列表：

```
选择课表
──────────────────
我的课表            当前
辅助课表
──────────────────
＋ 新建课表
```

- 点一下切换。切换后标题、周视图、今日页、桌面组件一起跟着换。
- 长按某一行可以**重命名**或**删除**；最后一张不许删，会提示「至少要保留一个课表」。
- 删掉的课表连同它的课程、背景、导入记录一起删除，删前二次确认。

存储上每张课表是一个独立的偏好文件，互不影响：

| 课表 | 存储 |
|---|---|
| 第一张（`main`） | `timetable-v1` —— **1.x 的老数据就躺在这儿，所以升级后什么都不用迁移** |
| 新建的（id 如 `m3k9x`） | `timetable-m3k9x` |
| 索引（有哪几张、当前是哪张） | `timetable-index-v1`，一个纯文本小文件 |

索引逻辑下沉到了核心库 `TimetableIndex`：一行版本号 + 一行 current + 每张课表一行，字段做 URL 编码（课表名是用户输入，可能有引号、空格、表情），因此不用依赖 `org.json`，可以在纯 JVM 里测。

## 导入跟着当前课表走

「管理 → 从教务系统导入课表」现在写进的就是你当前选中的那张：

- 导入页开头写明「直接写入当前课表「××」」，「导入会替换当前课表「××」」。
- 导入成功的提示也带课表名：「已写入 32 门课（2026-2027 学年 第 1 学期）到「我的课表」」。
- 备份恢复的确认框同样写明会覆盖哪一张。

于是常见用法变成：新建一张「下学期」→ 切过去 → 导入；旧学期的课表原封不动留着。
