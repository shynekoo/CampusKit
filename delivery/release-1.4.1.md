# CampusKit 1.4.1

2026-11-15。版本代码 136，`delivery/CampusKit-1.4.1.apk`，4,866,914 字节，
sha256 `42a88a3634c37f5b1a66b88314f91886f035e2b3d50f8900d1a2409a58ca953c`。
签名密钥与 1.4.0 相同，可直接覆盖安装；课表、趣智登录状态、设置都保留。

这一版按你提的四点改，另外把成绩那条 404 的成因往前推了一步。

## 1. 场地类型默认「多媒体教室一」

| 项 | 1.4.0 | 1.4.1 |
| --- | --- | --- |
| 场地类型 | 全部教室（`cdlb_id` 留空） | **多媒体教室一**；学校没有这项时退到任意「多媒体…」，再退到全部教室 |

默认值来自学校页面自己的 `cdlb_id` 选项，按**名称**匹配（先精确「多媒体教室一」，
再含「多媒体」），不是写死的编号，所以学校调整选项顺序或改编号都还认得出来。

## 2. 节次按「一节课」选，不再按单节

你说的对：这里一节课就是两小节，1-2 是一节、3-4 是一节。原来勾单节，很容易勾出
「第一节」这种半节课的查询。现在：

- 多选弹窗里每一项是**一整节课**：`第 1-2 节 08:00-09:35`、`第 3-4 节 10:05-11:40`……
- 仍然是多选，第 1-2 节和第 5-6 节可以一次查。
- 存的形状是 `1-2,5-6`，发给学校的 `jcd` 是这几节的并集（`1,2,5,6` → `51`），
  不会因为中间有空隙把没选的节次带上。
- 默认选「现在正在上的那一节」：按学校返回的每节开始/结束时间判断，而不是只看钟点。

## 3. 周次选择换成课表页那种 UI

原来是一个「第 1 周 / 第 2 周…」的列表对话框，现在是课表页同一个周次面板：

- 数字格子，当前选中的那格填色；
- 本周数字用强调色标出，底部多一个「回本周（第 N 周）」按钮；
- 学校校历里没有的周次（比如期末后的 19–30 周）仍然显示出来但不可点，
  比直接隐藏更好理解；
- 面板标题、入场动画、触控反馈都和课表页一致。

## 4. 离开页面不再立刻退出，改成 5 分钟后

1.4.0 是「一离开就退出」，于是从课表点回成绩、看一眼再点走，每来回一次就登录一次——
而学校的锁号计数数的正是登录次数。现在：

- 离开「成绩 / 空教室」→ **登记一个 5 分钟后的退出任务**，不是立刻退。
- 5 分钟内回到这个页面（或再查一次）→ 任务取消，会话继续用。
- 5 分钟到了还没回来 → 调 `/xtgl/logout.html` 并丢掉本地 Cookie，学校那边确实下线。
- 「退出登录」按钮仍然是**立刻**退出，不等这 5 分钟。
- 会话依然从不写盘，只有密码那份密文在密钥库里。

## 5. 成绩 404：不再盲猜地址，改成一页一页验证

你这次给的这行信息很关键：

```
HTTP 404（/cjcx/cjcx_cxXsgrcj.html?gnmkdm=N305005&layout=default）：系统维护页面 您访问的页面不存在哦
```

不是我原先猜的「参数不对」或「POST 被拒」，是**这个地址在你们学校根本不存在**。
1.4.0 里读学校菜单那一步显然没读到东西，于是退回了写死的地址，正好撞上 404。

这一版把这件事按「先找到、再验证」重做：

1. **菜单解析补了正方真实写法**。正方的首页菜单大量是脚本生成而不是 `<a href>`：
   `openTab('成绩查询','/cjcx/cjcx_cxXsgrcj.html?gnmkdm=N305005','N305005')`。
   原来的解析只看 `href`，这种菜单一条都认不出来。现在同时扫脚本里的路径，
   并且优先认带 `gnmkdm=N305xxx`（正方成绩功能号）的链接，模块换到别的目录也认。
2. **菜单页读不到就读首页**（有些部署把菜单直接渲染在 `/` 上）。
3. **每个候选地址都真打开一次再算数**：返回 200 且页面里带学期选择框（`xnm`/`xqm`）
   才认定为成绩页；返回 404 或「页面不存在」就换下一个。候选顺序是
   菜单里的地址 → `/cjcx/cjcx_cxXsgrcj.html?gnmkdm=N305005` →
   `/cjcx/cjcx_cxXsgrcj.html` → 带 `layout=default` 的原地址。
4. **报错说清试过哪些**：全都不行时提示变成
   「教务系统的成绩页打不开（试过 3 个地址：404 /cjcx/…、404 /cjcx/…）。学校菜单里也没找到
   成绩入口，可能这个学期关闭了网页成绩查询。」——这句话本身就是结论，
   能区分「学校关了」和「地址变了」。

安全边界也顺手收了一下：现在只允许访问 `/cdjy/`（空教室）和 `/cjcx/`（成绩）两个目录；
唯一例外是**学校菜单自己点名**的成绩页（带 N305 功能号），且只读。
