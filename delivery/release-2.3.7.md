# 科信小助手 2.3.7

版本码 166 · 2026-11-16

## 这一版解决什么

上一版的诊断结果指向了另一条开启路径：同样的账号、同样的凭据、同样的版本头，旧路径仍被「请升级最新版APP」挡回，而这条新路径返回的是「设备当前状态下，无法操作」。前者是版本协商在业务逻辑之前退回的请求，后者是业务逻辑跑完之后给出的状态判断——**说明这条路径被接受了，参数也过了校验**。

## 改了什么

- **开启用水改走新路径**，参数顺序与该路径被接受时的形态一致；其中一个与设备模式有关的参数取自设备自身返回的字段，不自己编。若该字段越界（不在 0–999），拒绝发送，不拿猜出来的值去打设备。
- **「设备当前状态下无法操作」有专门的说法**：不再笼统地说「可以重试」（同样请求再点一次结果一样），而是写明「未下发任何指令：设备当前不接受开启，常见原因是账户余额为 0 或设备刚被他人占用」。
- **余额为 0 时提前提示**：设备就绪但钱包余额为 0，页面直接写「开启多半会被拒，请先在原版慧生活充值」。只是提示，不拦人——后付费、赠送额度、不同商户钱包的规则我们看不全，替服务端拦人可能挡掉本来能开的设备。
- 结束用水仍走原有路径。

## 需要注意

「设备当前状态下无法操作」究竟是余额为 0 还是别的状态，只有再点一次才知道。这次诊断信息里余额是 0，所以余额是最可能的原因。若充值后仍被拒，把页面提示和 ⓘ 里的诊断信息发我。
