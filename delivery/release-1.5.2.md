# CampusKit 1.5.2

2026-11-16。版本代码 147，`delivery/CampusKit-1.5.2.apk`，
sha256 `49ba57eeeb99c9beda755fad338cac54ff33ffdfa297d31adfca03bd074f978d`。
签名密钥与 1.5.1 相同，可直接覆盖安装；课表、账号、登录态都保留。

这一版只改一件事：内嵌网页的「返回」。

## 问题

学校官网（河工程 / 科信）点进去是应用内的 WebView，但顶部 `‹ 返回` 绑的是 `finish()`——
无论你在站内翻到第几层，一按就直接退回桌面，等于整个窗口被关掉。
系统返回键其实是好的（有历史就 `goBack`），只有那颗按钮是错的；
同一个毛病在「教务系统」门户和「查成绩 / 空教室」页也存在。

## 改法

新增 `client/android/src/io/qzxy/lite/preview/WebBack.java`，把「回上一页 / 关窗」判定收在一处：

- `WebBack.go()`：`web.canGoBack()` 为真就 `goBack()`，否则才 `finish()`。
- `WebBack.caption()`：按钮文字跟着历史走——有上一页时是 `‹ 返回`，没有时是 `✕ 关闭`。

三处内嵌网页的顶部按钮、`onBackPressed()` 全部改走这两个方法，
并在 `onPageFinished` 与 `doUpdateVisitedHistory` 里刷新按钮文字
（后者覆盖 `history.pushState` 这类不触发 `onPageFinished` 的站内跳转）。

| 页面 | 之前 | 现在 |
|---|---|---|
| 河工程官网 / 科信官网 | `‹ 返回` → 直接 `finish()` | 有历史回上一页；只有首页时按钮显示 `✕ 关闭` 才退出 |
| 教务系统门户 | 同上 | 同上（页面内翻菜单也能退回来） |
| 查成绩 / 空教室 | 同上 | 同上 |

首页 / 刷新 / 站内跳转逻辑不变：跨域外链仍交给系统浏览器，附件下载也仍然交出去。
