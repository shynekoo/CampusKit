# CampusKit 1.4.5

2026-11-15。版本代码 140，`delivery/CampusKit-1.4.5.apk`，
sha256 `cd65e84d7b8f8a3f963302d103a1a8ef13b86127d00381c600d3cd81a9905497`。
签名密钥与 1.4.4 相同，可直接覆盖安装；课表、趣智登录状态、教务账号都保留。

这一版做两件事：**主页教务区加三个入口**，以及**课表导入改成选学期后自动完成**。

## 主页「教务」卡片

原来只有「成绩」「空教室」两个按钮，现在多了三个：

| 入口 | 点进去做什么 |
| --- | --- |
| 教务系统 | 用已保存的教务账号在后台自动登录，把会话 cookie 放进内置浏览器后再打开正方首页，不用再输账号密码 |
| 大学官网 | 用系统浏览器打开 `https://www.hebeu.edu.cn/` |
| 科信官网 | 用系统浏览器打开 `https://kexin.hebeu.edu.cn/` |

两个官网地址都是查证过的官方站点，且都用 HTTPS（本应用禁止明文流量）。
「教务系统」页只加载 `*.hebeu.edu.cn` 的 HTTPS 地址，证书错误直接停止，不保存表单数据、
不接收第三方 cookie；没保存账号或学校要验证码时会退回学校自己的登录页，不会白屏。
页面里还有「教务账号」「退出登录」按钮；离开页面仍沿用之前定的 5 分钟延迟登出。

## 课表导入：选一个学期就自动导完

原来的流程是：打开网页 → 自己登录 → 在网页里选学期、切表格式课表 → 点「读取当前课表」→
核对确认。现在「我的课表」菜单第一项改成**从教务系统自动导入**：

1. 用课表页那套底部面板和数字滚轮选**学年 / 学期**（最近 6 个学年 × 学校使用的学期码）。
2. 点「自动导入该学期课表」：读已保存的账号 → 原生自动登录 → 直接请求教务课表查询接口 →
   转换成课程 → **直接写入课表**，不再需要浏览器和手动点读取。
3. 结果会告诉你导入了几门课、跳过了几条字段不完整的记录，并给一次**撤销**机会
   （导入前的课表留了一份）。导入是按学期**替换**课表，不再把两个学期的课堆在一起。

课表查询接口不再靠猜：先打开学校自己的课表页，从页面脚本里读出它调用的查询地址，
再和内置的几个 正方 常见地址一起尝试；每个地址试两种参数形态，最多 12 次，
只接受返回 `kbList` 的响应。字段解析（星期、节次 `1-2` / `01-02` / `0102`、周次 `1-16周`、
单双周、教室、教师）走的是**现有 PDF / 网页导入同一套严格校验**，
任何一条不完整的记录会被跳过并计数，不会悄悄写错课表。

**网页手动导入没有删**，作为第二项保留：万一这个学校的接口改名或要验证码，
点「改用网页手动导入」还能走原来的路，结果回到原来的「核对教务课表」确认框。

- **没做到的**：依然没有真机（adb 无设备）。「自动登录后能不能读到这个学校的 kbList」
  必须装上去点一次才知道。本版能保证的是：失败不会动原课表、报错会列出试过的地址、
  旧的手工导入仍然可用。

如果自动导入没成功，把整句报错发我——里面带每个试过的地址和它的失败原因；
