## 二、更新内容（分模块）

### 界面与动效

- 常驻主界面 + 动画底栏：底栏只构建一次，胶囊用 `translationX` 移动，选中色插值；快速连点从当前位置续接。
- Tab 切换：新页 alpha 0.7→1、±8dp 位移、220ms；旧页 180ms 淡出；系统关动画时直接到终态。
- 滚动位置：切回某个 Tab、旋转 / 分屏、换主题后都留在原位置，不再跳回顶部。
- 跨周跳转：先提交周次再整屏滑页（190ms），落地帧即目标周；相邻一周仍走 Pager 滑页。
- 课表圆角默认 8dp → 20dp；偏好里已有 `radius` 的读者保持自己的值。

### 学业情况

- 课组可展开：点叶子课组才请求该课组课程，取过即缓存，再点不重复请求。
- 课程行显示课程名、成绩（无成绩显示在读 / 未修 / 未过）、学分；未通过与在读降为次要色。
- 修复「有学分却显示没有课程记录」：学校把课组课程分计划内 / 计划外两个端点，按 `jdkcsx` 二选一；
  此前一律请求计划内，导致通识选修、公共艺术等计划外课组拿到空数组。
- 修复父行误展开：只有叶子课组可点。
- 汇总卡补上「未通过」「计划外通过」，按学校给的六个数字分两行显示。

### 更新日志

- 更多 → 更新日志：按版本卡片展示，最新版默认展开，历史版本点击展开；数据随包内置、离线可读。
- 当前安装的版本若还没收录，会显示「此版本尚未正式发布」，不会把开发包误标成正式版。

### 隐私与安全

- `LegalText` 重写隐私说明（8 节）与使用公告（7 节），弹窗与整篇页面读同一份文字。
- 按实际行为纠正 5 处声明：教务密码的加密存储、不提供充值 / 不接收支付密码、四个网络端点等。
- 移除从未使用的 `ACCESS_WIFI_STATE`，权限 5 → 4 项；未新增任何权限。
- 公告 `VERSION` 2 → 3，升级后会再看一次。

### 诊断日志（本节是新功能）

- 结构化事件：`日期 时间.毫秒 等级 [模块] 事件代码 trace=… thread=… 字段=值`；失败自动带稳定原因码
  （`NETWORK_TIMEOUT` / `PARSE` / `AUTH_REJECTED` / `CAPTCHA` / `VERIFY` …）。
- 四级 + 崩溃：INFO / WARN / ERROR / CRASH；崩溃同步有界落盘后把异常原样交回系统处理器。
- 已接入：教务登录四阶段、课表候选端点 / 解析 / 写入、网络状态与耗时、慧生活、支付宝、趣智、更新校验。
- 存储：256 KB × 4（约 1 MB）、历史保留 7 天、整文件轮转；写盘走队列，不阻塞主线程。
- 页面：等级 / 模块筛选、点开看字段与堆栈、单条复制、按筛选或全部复制、UTF-8 导出（系统文件选择器）、
  清空二次确认、每次 40 条分页；另有「故障报告」页。
- **默认关闭**：正式版带页面但不记录，用户遇到问题自己打开；逐帧、逐请求的细节事件只在
  `--diagnostics` 内部构建里。

## 三、升级注意

- **版本代码 208**，可直接覆盖 2.5.7（197）及更早版本；课表、账号、偏好保留。
- 签名证书未变（`CN=QZXY Local Preview`），覆盖安装不会要求卸载。
- 改过课表圆角、主题色的读者升级后仍是自己保存的值（默认值只影响没改过的人）。
- 升级后首次启动会再弹一次使用公告（文案改版，`NoticeDialog.VERSION = 3`）。
- **不要**把 `--diagnostics` 或 `--field-water` 构建发到更新通道：包名同为普通版，误传会污染更新链路。

## 四、已知问题与未验证项（如实）

- **真机未验收**：底栏胶囊位置与连点、切页动画与滚动恢复、跨周滑页、320dp 窄屏、系统大字体、
  深色与自定义主题、返回手势完成与取消、系统关动画，均只有静态守卫与编译期证据。
- **诊断页真机流程未验**：开关 → 复现 → 导出 → 另一台设备打开、长日志滚动、崩溃后重启读取。
- 诊断只覆盖**未捕获的 Java 异常**：ANR、native crash、系统杀进程不会留下记录；关闭开关时连崩溃也不写。
- 学业情况的课组明细依赖学校页面结构（`jdkcsx`、两个只读端点），学校改版会失效并给出明确失败提示。
- 日志不含课程内容与账号，因此「某门课名字错了」这类问题仍需用户描述。
