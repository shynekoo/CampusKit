# CampusKit 1.5.1

2026-11-16。版本代码 146，`delivery/CampusKit-1.5.1.apk`，
sha256 `a461a19602d9d334ddd300b7a6e69f542ec0d0b29e9c803f066ce194a4aeea28`。
签名密钥与 1.5.0 相同，可直接覆盖安装；课表、账号、登录态都保留。

这一版只动界面：扫码页重做、慧生活手动输入删掉、两个学校官网去掉「浏览器」。

## 扫码页（慧生活798 / 趣智校园共用同一页）

改的是「看什么、按什么」，相机、解码、票据兑换和跳转逻辑一行没动。

| 位置 | 之前 | 现在 |
|---|---|---|
| 顶部 | 一行「返回」+ 一行大标题 | `‹ 返回` + **扫一扫** + 一行说明（`慧生活798 · 对准设备上的二维码` / `趣智校园 · …`） |
| 取景区 | 一块纯黑 SurfaceView，没有边界提示 | 深色圆角舞台 + **四角取景框** + 框外半透明压暗 + 底部提示胶囊「把设备码放进框内」 |
| 手电筒 | 和「重新扫描」并排的整行按钮，不支持时是一行灰掉的「此相机不支持手电筒」 | 取景框右上角的 44dp 圆形按钮；**亮起时变白底蓝图标**，相机不支持时**整个不显示** |
| 变焦 | 一直显示，不支持变焦时是一条 1.0× 的死滑杆 | 只在相机真支持时出现 |
| 状态文字 | 固定 56dp 高的滚动条，长报错被裁掉 | 白色圆角卡片，随内容长高，**可长按选中复制**（报错原文能直接复制出来）；卡片再长，取景区也至少保留 200dp |
| 底部按钮 | 「重新扫描」「手电筒」一行 +「查询设备资料」+「查询订单状态」三行堆叠 | 只留一行「重新扫描」；另外两个按钮只在只读构建出现（用水构建识别后直接进支付宝） |

另外：扫码成功后取景框提示会隐藏，重新扫描时恢复；识别失败的文案也改成「点『重新扫描』再对准一次」，
不再引导去手动输入。

## 慧生活手动输入已删除

「手动输入设备编号」按钮、输入框、以及失败文案里那句「或直接手动输入设备上的编号」全部移除。
1.4.8 加它是为了排查「扫不出来」，现在票据兑换的路子已经通了，它只会让人绕过扫码。

## 学校官网去掉「浏览器」

河工程官网、科信官网顶部工具条只剩 `‹ 返回 / 首页 / 刷新`，不再一键把页面甩给系统浏览器。
页面内的行为保持不变：**跨域外链**仍然交给系统浏览器（否则站外链接点不动），
**附件/PDF 下载**也仍然交出去（裸 WebView 渲染不了）。

## 验证到哪一步

- 核心断言 886 项通过（与 1.5.0 相同，这一版没有改核心逻辑）。
- `aapt2` 读到 versionCode 146 / versionName 1.5.1，v2/v3 签名校验通过。
- 已核对 APK 内 dex：`手动输入设备编号` 字符串已不存在，新文案（`扫一扫`、`把设备码放进框内`）已进入。
- **没做到的**：仍无真机，取景框比例、手电筒按钮位置、状态卡片高度只能在设备上看。
  框的边长取 `min(宽×0.74, 高×0.62)`（上限 320dp、下限 150dp），略高于画面中线——
  如果在你手机上框偏大或偏小，告诉我屏幕尺寸，我按数值调。
