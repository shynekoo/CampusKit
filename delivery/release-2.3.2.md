# 科信小助手 2.3.2

2026-11-16。慧生活登录页顶部加「支付宝一键登录」，手机号验证码原样留在下面。

## 为什么改

2.3.1 的登录页把服务器的原话显示出来了，那句是「请升级最新版应用」。查下去发现不是版本号的问题：

- 图形验证码接口、发短信接口在 31005 下都还能正常返回；
- 登录接口多了一个 `openCode` 字段，塞一个假值进去服务器会尝试去支付宝兑换，返回「系统错误」；
- 官方 3.1.5 的登录页里本来就带着支付宝快捷登录（`AuthTask.authV2`），授权串是写死的，拿回 `auth_code` 后作为 `openCode` 发给同一个登录接口。

也就是说短信只是留着，账号登录已经被指向支付宝授权了。

## 改了什么

**登录页**：同意条款下面就是「支付宝一键登录」，一整行蓝色按钮；再往下一条细线写着「或使用手机号验证码」，原来的手机号、图形验证码、短信码一个没删。

**授权流程**（`AlipayLogin`）：

1. 工作线程里调 `AuthTask.authV2(authInfo, true)`，支付宝在前台弹出授权页；
2. 解析回来的 `resultStatus` / `result`，要求 `9000` + `result_code=200`，取 `auth_code`；
3. 把 `auth_code` 作为 `openCode` POST 到 `/api/v1/acc/login`，拿 `data.al.uid/token`；
4. 走原来的 `LifeSessionVault` 加密保存，成功后的行为与短信登录完全一致。

失败按原因说话：`6001` →「已取消支付宝授权」；SDK 抛错 →「没能唤起支付宝，请确认已安装并登录支付宝」；服务器拒绝 → 服务器原话。

**构建**：支付宝官方 SDK 15.8.42（`com.alipay.sdk:alipaysdk-android`，Maven Central，SHA-256 固定）。没有 Gradle，AAR 手工合并：`classes.jar` 进 javac 与 d8；6 个 Activity、`org.apache.http.legacy`、两条权限抄进清单；3 条字符串抄进 `res/values/alipay_sdk.xml`，并用 `aapt2 link --extra-packages com.alipay.sdk` 生成 SDK 自己的 `R`。见 `client/THIRD_PARTY.md`。

APK 从 5.17 MB 涨到 5.34 MB。

## 必须说清楚的

- **授权串是慧生活自己的身份**：`app_id=2021002141696106`、`pid=2088631403836084`，签名 344 字符，来自官方 3.1.5 的登录页。所以支付宝授权页显示的是「慧生活798」，不是「科信小助手」。这是他们的 appid，出风险也算在他们头上，登录页上已经写明这一点。
- **能否成功由支付宝决定**：SDK 会把调用方的包名与签名一并上报，支付宝如果按 appid 绑定校验，我们这个自己的签名会被拒。这一版把流程完整做出来了，但没有真机验证——这台机器没有设备也没有模拟器，`AuthTask` 那一步只能装到手机上才知道。
- **失败不会挡路**：授权失败只写一行状态，手机号表单仍在原位，可以立刻改走短信。
- **服务端那一关仍在**：即使拿到了 `auth_code`，`/api/v1/acc/login` 仍可能回「系统错误」或「请升级最新版应用」。如果这样，问题就不在客户端了。

## 验证

- 核心断言 1034 项通过（本次没有新增可离线测试的逻辑，`AlipayLogin` 依赖 Android SDK）；
- 构建通过；`aapt2` 读到 `versionCode=160 / 2.3.2`，`resources.arsc` 里有 `alipay_standard_sdk_loading*` 三条字符串，清单里 6 个 SDK 页面都已注册；
- APK 内确认含 `AlipayLogin`、`com/alipay/sdk/app/AuthTask`、`openCode`；
- 线上清单 `2.3.2 / 160 / 5338780 bytes / sha256 ce458ce6…893db` 与下载回来的包逐字节一致；
- **支付宝授权、服务端兑换、登录成功这三步均未在真机上跑过**。

## 装不上或登录失败时

- 授权页没弹出来：确认手机装了支付宝并已登录；没有的话会走 SDK 的 H5 授权页。
- 支付宝里点了确认，回来显示「支付宝授权未完成（状态 4000/5000/6001）」：把状态码发我，那串数字能定位是签名被拒、appid 被限制还是网络问题。
- 显示「系统错误」：服务器没有接受这次 `openCode`，需要抓一次请求时间点。
