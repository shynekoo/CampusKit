# CampusKit 1.5.4

2026-11-16。版本代码 149，`delivery/CampusKit-1.5.4.apk`，
sha256 `91ce9c16a5ef21a31bac4d6525115ba56cdcaddb0402e3720d0694d76af596f7`。
签名密钥与 1.5.3 相同，可直接覆盖安装；课表、账号、登录态都保留。

两件事：启动时的**使用公告**，「账号」页的**数据与隐私**。

## 使用公告

每次打开应用弹一次，正文七段：不是官方应用、账号只在本机、课表来自学校、没有服务器与统计、
涉及钱的操作回原版、随时可清除、风险自担。面板结构：

```
使用公告
CampusKit 是个人开发的第三方客户端
─────────────────────
（正文，超过半屏时可滚动）
─────────────────────
[   知道了，开始使用   ]
□ 以后不再提醒
```

- 按钮在复选框**上方**，顺序按你说的排。
- 只有点按钮才记录选择：勾了「以后不再提醒」→ 写入 `notice-v1/silenced`，下次不再弹；
  没勾 → 照旧每次都弹。点对话框外面或按返回键关掉**不算**选择，下次还会出现。
- 静音记的是**版本号**不是布尔值。以后我要改公告文字，把 `NoticeDialog.VERSION` 加一，
  所有人（包括已经勾过的人）会重新看到一次——改内容却没人看见，等于没改。
- 正文用 `ScrollView` 且上限为屏高 52%，小屏也不会把按钮顶出屏幕。

## 数据与隐私

入口在「账号」页第三个条目（趣智校园、慧生活798 下面），页面分五块：

| 板块 | 内容 |
|---|---|
| 保存在这台手机上 | 三份登录会话（加密文件、不存明文密码）、课表/开学日期/背景、组件与公告偏好 |
| 不会离开这台手机 | 没有账号服务器、没有统计与广告；列出全部请求目的地：`v3-api.china-qzxy.cn`、`i.ilife798.com`、`jwglxxfwpt.hebeu.edu.cn`、两个学校官网、淘宝/菜鸟（仅点身份码时交给系统） |
| 权限 | 网络、相机（只取景，不拍照不录像不保存），并说明没有位置/通讯录/短信/存储权限 |
| 清除 | 两级：**清除登录状态**（三份会话，课表保留）／**清除全部本机数据**（再加课表、背景、组件与公告偏好），都要二次确认 |
| 使用公告 | 「重新查看使用公告」，只展示，不改变你之前勾的静音选择 |

实现上有个必须绕开的坑：`AccountVault.clear()` 内部有 `workerOnly()` 检查，在主线程调用会抛
`IllegalStateException`。所以三份会话的删除放在单独线程（`privacy-wipe`）里做，结束后回到主线程
更新状态；「清除全部」之后用 `FLAG_ACTIVITY_CLEAR_TOP` 重建主页，否则首页还捧着内存里那份已删除的课表。

## 顺手修掉的一处

「账号」页底部和短信登录页底部都硬编码着 `CampusKit 1.0.9`，早就不对了。现在读安装包的真实
versionName（`AppUi.version()`），显示 `CampusKit 1.5.4`。

## 验证到哪一步

- 核心断言 886 项通过（与 1.5.3 相同，这一版没有改核心逻辑）。
- `aapt2` 读到 versionCode 149 / versionName 1.5.4，v2/v3 签名校验通过。
- APK 内已确认：`PrivacyActivity` 注册在清单里，`使用公告`、`以后不再提醒`、`知道了，开始使用`、
  `数据与隐私` 四个字符串都进了 dex。
- **没做到的**：没真机。公告弹窗在 5 寸小屏上的实际留白、`CappedScroll` 的滚动位置、以及清除后
  主页重建的动画，只能在设备上看。若公告在你的手机上偏高或偏矮，告诉我屏幕尺寸，我按 dp 调。
