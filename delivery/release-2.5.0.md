# 科信小助手 2.5.0 发布说明

**发布日期**：2026-11-16 · 版本代码 170 · `delivery/科信小助手-2.5.0.apk`（5342876 字节，sha256 `8782e26c…62f131`）

## 变更

- **开启用水不再弹支付方式选择**。此前按服务端返回的计费项顺序弹出单选列表，默认项可能落在余额为 0 的商家钱包上，这也是前几版反复撞上「设备当前状态下无法操作」的原因之一。现在固定使用**支付宝免密**——本机账单里每一笔成功水费都是它。点「开启用水」→ 确认弹窗（固定文案「支付方式：支付宝免密」）→ 直接发送开启请求。
- 开启前的最终核对仍会重新拉一次设备详情：若服务端这次没有提供支付宝免密，提前报「设备未提供支付宝免密（可用：…）」并列出可用方式，不盲发请求。
- 「设备当前状态下无法操作」的提示改为「可能是设备刚被他人占用或支付宝免密代扣未生效」，不再引导换支付方式。

- 业务码解释表仍沿用此前整理的结果。
