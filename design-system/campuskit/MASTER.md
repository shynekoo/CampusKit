# CampusKit 1.0 — 原生 Android 设计规范

依据用户指定的 UI UX Pro Max skill（2026-10-06 安装并读取），运行 `calendar scheduling productivity --design-system`，采用命中的 Flat Design 和 Calendar 蓝色方向。首个 student planner 检索误配时尚粉色，未采用。生成器的营销网页结构不适用于本项目，不使用；原生 Java Views 没有匹配的 stack 专项，按技能原生移动端规则落地，不迁移框架。

- 风格：日常校园工具，信息优先。没有渐变、夸张标题、装饰阴影和宣传文案。
- 色彩：背景 #F6F7F9，内容 #FFFFFF，正文 #202735，次要文字 #596575，操作 #275DAD，分隔 #E3E7ED。统一为 AppUi 常量。只提供明确浅色主题，系统深色下禁止自动反色。
- 字体：Android 系统中文字体，不下载拉丁展示字体。标题 22–24sp，正文 15–16sp，辅助 12–13sp；保留系统字号缩放。
- 形状：卡片 12dp，按钮 10–12dp；主要按钮 52–56dp，内容增大时允许高度扩展。间距 4/8/16/24dp。
- 图标：AppUi 原生路径绘制，统一 24 单位坐标和 1.7 线宽；不以字母、汉字、emoji 代替导航图标。独立图标保留可访问名称与 48dp 点击区域。
- 今日：校园服务一排四入口；今天课程采用时间列、细色条与课程信息；已有课程色只作识别标记。已结束课程保留删除线。
- 课表：保留横向换周、课表背景及各门课的既有配色；收简标题、帮助说明和周次操作。保留按钮换周以支持不便滑动的用户。
- 账号：两项账户列表，简短状态／功能说明；版本与第三方身份说明放在底部。登录页说明数据去向，不写开发过程。
- 设备：顶部返回、刷新、详情；设备卡和单个主要动作。进度、异常、结束账单状态按需显示，不隐藏真正尚未结算的状态。
- 正式版身份：应用名 CampusKit，版本 1.0.0；移除公开页面的测试版、开发版、过时“功能未接入”等文案。未验收项目记录在发布说明，不编造已测结果。

验证按技能 pro-rules：小屏、横屏、大字号、系统深色与关闭动画；检查触摸反馈、图标标签、系统栏、文字溢出和对比度。实际不支持的配置需在交付记录注明。
